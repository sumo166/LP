底部说明 / 计算假设
1. 代币A 为报价币，代币B 为基准币，价格口径为 USDG/PONS。
2. 代币B价格（投入LP时）用于计算初始投入市值；当前 PONS 价格用于计算当前持仓和收益。
3. 流动性 L 由初始总价值（A数量 × A价格 + B数量 × 投入价）联合求解，确保在投入价格处 LP 市值 = HODL 市值 = 初始总价值。
4. HODL 市值 = 初始A数量 × A价格 + 初始B数量 × 当前 PONS 价格。
5. LP 市值 = 按 V3 宽区间和当前价格计算的实际持仓市值（基于上述流动性 L）。
6. 无常缺口 = HODL 市值 - LP 市值。
7. LP 绝对浮亏 = 初始投入市值 - 当前 LP 市值。
8. 回本手续费 = max(0, 无常缺口)（即 LP 相对 HODL 的落后金额，价格涨、跌两个方向都计算）。
9. 回本时间 = 回本手续费 ÷ 1h收益；1h收益 = 当前LP市值 × APR / 8760。
10. 表格价格范围 = [下限 - 表格价格扩展, 上限 + 表格价格扩展]，均匀生成价格点。
11. 所有金额显示为完整美元数值（保留两位小数），不使用 K/M 缩写。
12. 输入任何参数后，表格和摘要将实时自动刷新，无需点击按钮。

# LP
底部说明 / 计算假设 1. 代币A 为报价币，代币B 为基准币，价格口径为 USDG/PONS。 2. 代币B价格（投入LP时）用于计算初始投入市值；当前 PONS 价格用于计算当前持仓和收益。 3. 流动性 L 由初始总价值（A数量 × A价格 + B数量 × 投入价）联合求解，确保在投入价格处 LP 市值 = HODL 市值 = 初始总价值。 4. HODL 市值 = 初始A数量 × A价格 + 初始B数量 × 当前 PONS 价格。 5. LP 市值 = 按 V3 宽区间和当前价格计算的实际持仓市值（基于上述流动性 L）。 6. 无常缺口 = HODL 市值 - LP 市值。 7. LP 绝对浮亏 = 初始投入市值 - 当前 LP 市值。
